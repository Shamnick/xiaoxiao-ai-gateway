API 文档

OpenAI 兼容接口，改一行 base_url 即可接入；支持流式输出、多上游自动路由与失败回退。

快速开始 认证 对话补全 流式输出 模型列表 错误码 计费规则

快速开始

注册后到控制台「我的 Key」签发一把密钥，然后：

curl http://127.0.0.1:8848/v1/chat/completions \ -H "Authorization: Bearer $YOUR_API_KEY" \ -H "content-type: application/json" \ -d '{ "model": "GPT-6-Astra-max", "messages": [{"role":"user","content":"你好"}] }'

Python / Node 直接用官方 OpenAI SDK，把 base_url 指向本平台即可。

from openai import OpenAI client = OpenAI( base_url="http://127.0.0.1:8848/v1", api_key="sk-yt-...", ) print(client.chat.completions.create( model="GPT-6-Astra-max", messages=[{"role": "user", "content": "你好"}], ).choices[0].message.content)

认证

所有请求使用 Bearer Token：

Authorization: Bearer sk-yt-xxxxxxxxxxxxxxxx

密钥仅在创建时完整显示一次，请妥善保存；泄露后可在控制台停用并重新签发。

对话补全

POST /v1/chat/completions
参数类型说明
modelstring模型 ID，见 模型广场 或 GET /v1/models
messagesarray[{role, content}]，角色支持 system / user / assistant
streambooltrue 时以 SSE 逐块返回
temperature / top_p / max_tokensnumber透传给上游模型

流式输出

curl -N http://127.0.0.1:8848/v1/chat/completions \ -H "Authorization: Bearer $YOUR_API_KEY" \ -H "content-type: application/json" \ -d '{"model":"GPT-6-Astra-max","stream":true, "messages":[{"role":"user","content":"写一句 slogan"}]}'

模型列表

GET /v1/models

返回 OpenRouter 风格字段：context_length、architecture、pricing、top_provider。

错误码

HTTPtype含义
401invalid_api_key密钥无效
402insufficient_quota余额不足
402quota_exceededKey 额度用尽
403key_disabled / key_expired密钥停用或过期
403model_forbidden该 Key 未授权使用此模型
429rate_limited超出 RPM / TPM 限制
502upstream_error所有上游均失败

计费规则

每次调用扣费 = 固定请求费 + 输入 token × 输入单价 + 输出 token × 输出单价，单价见 价格。

余额不足时返回 402 且不产生调用；每次调用记录可在控制台「用量统计」查看。
