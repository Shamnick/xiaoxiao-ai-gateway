订阅说明

  1. 无限额度：标「无限额度」的套餐在有效期内不限调用次数、不限上下文长度，全站模型都能用，只受并发数限制。
  2. 每日次数：标「每日 N 次」的套餐每天最多调用 N 次，北京时间每天 0 点自动清零； 每次调用固定算 1 次，调旗舰模型还是轻量模型都一样，与上下文长度无关。
  3. 并发是什么：套餐名里的「单并发 / 双并发 / 五并发」是这把密钥同一时间最多能同时跑几个请求。 多开窗口、多个 Agent 同时干活请选多并发；超出并发的新请求会被直接拒绝（不扣次数），等前面的请求结束再发即可。
  4. 与积分互不影响：订阅用量走套餐，不扣钱包积分；钱包积分仍可用于自行签发的普通密钥。
  5. 独立密钥：订阅成功后在「我的订阅」里复制专属 sk- 密钥，只有这把密钥享受订阅额度。
  6. 续费不换密钥：重复购买同一套餐只会给原密钥延长有效期（从原到期时间往后顺延），密钥本身不变，代码里不用改。
  7. 可用模型按套餐而定：点套餐卡片上的「查看可用模型」可看完整清单；未限定的套餐可用全部已上架模型。
  8. 额度、并发与有效期由套餐决定，不可自行修改；如需暂停使用，可在「我的 Key」里停用这把密钥。 早期标有「总次数」的套餐是一次性额度，用完即止，续费会把新增次数累加上去。
  9. 付款后如长时间未开通，请联系在线客服人工处理。
